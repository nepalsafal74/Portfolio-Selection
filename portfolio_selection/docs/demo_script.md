# Demonstration Video Script (about 8 to 10 minutes)

The video is recorded and uploaded to a public video website. Test the link in a private
browser window before submitting.

| Time | Content | Show on screen |
|---|---|---|
| 0:00 - 0:40 | The problem: choosing assets under budget and risk limits | Title slide, README |
| 0:40 - 2:00 | Overview tab: asset statistics, Sharpe ratios, correlations | Dashboard, Overview tab |
| 2:00 - 3:30 | Algorithm comparison: greedy vs. optimal on a $5,000 budget | Comparison tab, metrics and picks |
| 3:30 - 5:00 | DP table explorer: move the stage slider and explain the recurrence | DP explorer tab, heatmap |
| 5:00 - 6:00 | Custom knapsack: enter a small example, show where greedy fails | Custom knapsack tab |
| 6:00 - 7:00 | Backtest and benchmarks: runtime grows with n; DP grows with budget | Backtest and Benchmarks tabs |
| 7:00 - 8:00 | Tests and repository: run the test suite, show the folder layout | Terminal, GitHub page |
| 8:00 - 9:00 | Results and limits: what the comparison shows and what it does not | Report figures |

Recording checklist: show the program running, the main inputs (budget, risk ceiling, number of
assets), the main outputs (picks, values, timings), and the algorithm behavior.
